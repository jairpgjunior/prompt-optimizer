# Prompt Optimizer

## Overview
Prompt Optimizer is a lightweight tool designed to refine and optimize AI prompts for platforms with strict input limitations, such as v0 Lovable and Bolt.dev. It ensures your prompts remain concise while retaining their intended meaning and effectiveness.

## Features
- **Character Limit Enforcement**: Adjusts prompts to fit within predefined constraints.
- **Text Cleanup**: Removes unnecessary spaces, special characters (*, #, etc.), and redundant words.
- **Efficient Copying**: Quickly copy the optimized prompt to your clipboard.
- **Smart Compression**: Retains key context while shortening verbose inputs.

## Use Cases
- AI development workflows where prompt length is restricted.
- Enhancing clarity and efficiency in prompt engineering.
- Streamlining interactions with AI-powered tools that impose strict character limits.
